# Sistema de Utilidades Java

Projeto desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastro de produtos.
- Registro do nome, preço e quantidade dos produtos.
- Venda de produtos.
- Controle de estoque.
- Cálculo do valor total das vendas.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- Maven

## Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Execute a classe `Main.java`.

## Objetivo

Este projeto foi desenvolvido para praticar Java e aplicar conceitos de orientação a objetos em um sistema simples de cadastro e vendas.
